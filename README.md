# Siper Antivirus

Siper, Pardus GNU/Linux için geliştirilen entropi tabanlı ve açıklanabilir bir güvenlik uygulamasıdır.

## Proje İçeriği

- SIPER-stage15.3/ — kaynak kodlar ve teknik belgeler
- kurulum/ — Debian kurulum paketi ve kurulum talimatları
- Proje Raporu.pdf — teknik proje raporu

## Kurulum

Kurulum için "kurulum" klasöründeki "SIPER-DEB-KURULUM.txt" dosyasını inceleyiniz.
