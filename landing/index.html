Defense signals you can inspect.

ELLIOT is designed to surface meaningful evidence locally, so a high-risk signal can be understood before a response is authorised.

Entropy intelligence

Whole-file and block-level Shannon entropy analysis helps identify unusual packed, encrypted, or obfuscated content.

01

Controlled decisions

Transparent policies support alert, monitor, warn, deny, terminate, and quarantine actions when explicitly authorised.

02

Native monitoring

Platform adapters connect Linux execution and runtime observability with Windows-native event telemetry.

03

Evidence over opacity

Signals can be traced to entropy, file type, permissions, and runtime context instead of a single unexplained verdict.

04

One local analysis path

From execution event to accountable response.

Each operating system uses its own native monitoring layer, while the deterministic analysis and local evidence model remain consistent.

A few important details.

Does ELLIOT require an account or cloud connection?+

No. The engine is designed to operate locally. This release path does not introduce central cloud management or remote event logging.

Which package will the button download?+

The page detects Windows and Linux browsers, selects the matching package, and lets you change that choice before downloading.

How are releases verified?+

Release assets and their checksums should be published together in the project’s GitHub Releases page before this site is made public.
